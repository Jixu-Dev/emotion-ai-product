## 🧠 Overview

**Emotion AI** is a full-stack sentiment analysis platform that combines a **Python-powered ML backend** with a sleek **TypeScript + Vite frontend**. It analyzes text, images, or user interactions to detect emotional patterns, classify sentiments, and deliver AI-powered insights through beautiful data visualizations.

---

## ✨ Features

- 🤖 **AI-Powered Analysis** — Machine learning models for emotion detection
- 📊 **Visual Dashboards** — Interactive charts and sentiment heatmaps
- 🐍 **Python Backend** — Robust ML pipeline with NLP processing
- 💎 **TypeScript Frontend** — Type-safe, modern UI with Vite
- 🔄 **Real-Time Processing** — Instant emotion classification on input
- 📱 **Responsive Interface** — Works seamlessly on all devices

## 🚀 Quick Start

### Backend
```bash
# Navigate to backend
cd backend

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the backend server
python app.py
```

### Frontend
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

---
